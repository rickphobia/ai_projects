# Course folders are two levels in: semester, then course

The Study folder is the tablet's `usm` folder, which holds one short semester folder with a folder per course in it (`usm/y1s1/circuit`, decision 0010 and the README's "Sync app"), not Drive's `Year 1/Sem 1/<course>`. So a folder two levels in is a Course folder by default (it was three), and the home screen opens on the semester folder at the top level (it opened a year and a semester) (owner, 24 Nov 2026: "fix the default directory position for course"). Marks saved before stay valid: a marked folder is a course at any depth.

**Trade-offs:** a Study folder laid out `Year/Sem/course` now needs each course marked by hand. A folder at two levels that isn't a course, such as a seniors' `circuit pyq` pair, needs unmarking once.
